## 为什么非要真实流量（不是锦上添花）

本平台的验收判据是：**维度 3 开放验收全绿 → 开放回流白名单 → 放量**。
维度 3 的验收对象就是**真实 error 现场**本身，它由真实用户触发。因此：

- **没有真实流量，维度 3 永远无法完成**——不是「做了但没验」，是**这个判据根本没有输入**。
- 目前平台上跑过的全部流量，都是**平台自己主动打 agent** 造的。这类流量能验链路通不通，
  但验不了「真实现场长什么样」：观察哨位、重推、requeue、停摆恢复这几条，
  都要真实用户触发的错误才会走到。

**一个具体的、已经在发生的退化**：平台的接口字典表至今 **0 行**。它的预期写点是
「事件上报时自动注册」，而实际没有任何真实调用走到那里 ⇒ 该表恒空 ⇒ 判定逻辑
**静默退化为「只靠 trace 内证据」**，少掉一路判据。这类问题**不会随代码写完而消失**，
只会有真实调用进来才暴露。
