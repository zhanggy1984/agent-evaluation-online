## 0. 口径声明（先说清本文件能信到什么程度）

1. **「已覆」的判据 = 存在具名探针场景在真库/真机跑过**，证据列到「探针名#场景号」，可 `docker exec obs-backend python /app/tests/integration/<probe>.py` 复跑复核。
